EMA'S KITCHEN — WEBSITE STARTER

Files
- index.html: page structure and content
- styles.css: responsive styling and brand palette
- script.js: menu, search, category filters, cart, demo checkout and demo admin dashboard

How to run
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or double-click index.html in a browser.
4. Internet is needed for Google Fonts and the remote food photos.

Before publishing
- Replace the sample phone number +234 000 000 0000 and WhatsApp number 2340000000000.
- Replace the email, physical address, social links and sample customer reviews.
- Confirm real menu items, prices, descriptions, delivery fee and business hours.
- Replace sample food image URLs with Ema's actual food photographs.
- Admin demo data is stored in the visitor's browser localStorage. It is not secure, shared, or connected to a real database.
- Checkout currently creates a local demo order and opens WhatsApp for manual sending. It does not process payments or notify the business automatically.
- For production, add a backend/database, admin authentication, image storage, order API, and a Nigerian payment gateway such as Paystack or Flutterwave. Verify payment server-side using the provider's webhook before marking an order paid.
- Set the official WhatsApp number in script.js in international format without + or spaces (e.g. 2348012345678).
